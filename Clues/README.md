# Loose Threads / Unpulled Threads / Lead Board

This page tracks **player-visible leads worth remembering**: clues the crew could still pull, unresolved questions that may matter, and campaign pressure points the GM can reuse without digging through every session page.

It is not a complete evidence dump. A lead belongs here when it is still actionable, high-value, and likely to matter at the table.

## How to use this board

- **Players:** start here when asking, "What did we leave unfinished?"
- **GM:** use this as a spoiler-safe reminder of threads that can become scenes, contacts, legwork, or complications.
- **Cindy:** after each session closeout, mark leads as new, touched, resolved, dormant, or superseded.
