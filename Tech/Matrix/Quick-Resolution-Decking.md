# Quick Resolution Decking

> **Optional and secondary.** The GM offers this shortcut when useful; the table never assumes it. The regular SR3 decking rules remain the default, especially for consequential Matrix runs. This procedure must not displace the normal rules or make decker upkeep such as utility ratings irrelevant. (p. 122; GM ruling, 2026-11-16)

This companion-book shortcut is intended for an unexpected, brief Matrix run when the GM has not prepared a full run or does not want to pause other events for a lengthy scene. The book offers either one quick test or a series of tests representing different aspects of the run. It does not provide a detailed sequence for the series option here, so no such procedure is added below. (p. 122)

Keep the fiction visible: describe system sculpting, IC, personas and events rather than only listing mechanical results. (p. 122)

## Single-test option

1. Make a quick, ordered list of information the decker wants or actions she hopes to take. Order items by difficulty or by the decker's priorities.
2. Make one **Computer (Decking) Test**, using all Hacking Pool available. The target number is the system's **Security Value**.
3. The system's **Security Code** sets the minimum successes: Blue 1, Green 2, Orange 3, Red 4. Each success beyond that minimum lets the decker obtain one item from the list.
4. Alternatively, skip the list and let each net success answer one question or resolve one particular action. This is an alternative way to spend the result, not an extra reward.

The book also gives a quick-resolution rule of thumb: actions per Matrix Combat Turn equal the number of Initiative dice rolled (for example, Initiative 6 + 3D6 gives three actions). This is a shortcut, not a replacement for the regular Matrix turn sequence. (p. 122)
